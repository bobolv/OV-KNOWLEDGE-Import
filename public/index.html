CONNECTION

连接 OpenViking

密钥只用于服务端连接，不会返回浏览器。

Windows Docker 容器访问本机 OV，使用 host.docker.internal。填写服务根地址，不含 /studio/home。

每份资料使用独立目录，原始内容与补录说明分别存储。现有导入任务保留提交时的连接配置。

IMPORT GUIDE

格式与处理方式

以 OV 实际解析结果为准，原件始终保留。

直接提交 OV

常用文档与表格

DOC / DOCX / DOCM / ODT / RTF
XLS / XLSX / XLSM / XLSB / ODS / CSV
TXT / MD / PDF / PPT / PPTX / HTML / EPUB

解析依赖由 OV 配置。扫描 PDF 的文字提取效果需要实测。
依赖视觉模型

图片资料

JPG / JPEG / PNG / GIF / WEBP / BMP

OV 官方图片理解为实验性能力，需要可用的视觉模型；上传不代表识别准确。
需要转换

WPS 专有格式

WPS → DOCX 或 PDF
ET → XLSX 或 PDF

使用 WPS 另存为标准格式，再在资料详情关联转换文件。不会仅修改扩展名冒充转换。

一份记录的入库过程

接收原件　→　按需补录　→　OV解析与索引　→　保存资料说明　→　完成与回读验证

补录只填写对后续查找有帮助的信息：项目、关联事件、发生时间原话、当前进展或使用目的。未知信息留空，不自动推断根因，不把技术方案写成实施结果。
